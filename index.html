Hi, I'm Anshuman Patel, a Software Engineer III at Precize, where I own the backend systems behind business-critical fintech workflows. I started in Civil Engineering at Government College of Engineering, Keonjhar, and moved into software because I wanted to build systems that scale, not structures that stand still.

In 2.5+ years, I've gone from writing REST APIs to owning backend architecture end to end: PostgreSQL and AWS infrastructure, production observability, and the trade-off calls that come with scaling a fintech platform. Two numbers I'm proud of: a 25x backend performance improvement and a 15x database throughput gain, both from finding the actual bottleneck instead of adding more infrastructure.

Day to day that's Node.js, TypeScript, and Fastify on the application side, PostgreSQL and Redis for data, and AWS (Elastic Beanstalk, Lambda, RDS, CloudWatch) for infrastructure, with Grafana keeping me honest about what's happening in production.

My resume has the full timeline, if you want it.
